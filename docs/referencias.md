# Fontes técnicas

Consultadas em 30/09/2026. São referências de tecnologia; o comportamento do protótipo e suas regras foram definidos para este projeto.

1. [Expo — Create a project](https://docs.expo.dev/get-started/create-a-project/): criação do projeto e suporte ao ambiente Windows.
2. [Expo — Develop websites](https://docs.expo.dev/workflow/web/): prévia e exportação web do mesmo app.
3. [React Native — Introduction](https://reactnative.dev/docs/getting-started): base da interface móvel.
4. [Callstack — React Native Slider](https://github.com/callstack/react-native-slider): controle deslizante, intervalo e eventos de interação.
5. [GitHub — GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow): branches, PRs e revisão.
6. [Semantic Versioning](https://semver.org/): formato das versões e distinção de versões iniciais.
7. [Node-RED — Working with messages](https://nodered.org/docs/user-guide/messages): referência para o contrato de integração futura.
8. [Expo — SDK 57](https://docs.expo.dev/versions/v57.0.0/): versões compatíveis de React/React Native e requisitos do ambiente.
9. [Expo — Using ESLint](https://docs.expo.dev/guides/using-eslint/): configuração de verificação do código.
10. [GBCR — nota técnica, julho de 2024](https://www.gbcr.org.br/wp-content/uploads/2024/07/Nota-Tecnica-GBCR-Pais-preocupados-mal-estar.pdf): cores e prioridades de Manchester exibidas no indicador manual. Ver docs/manchester.md.
