# Relato de problemas de segurança

Este projeto está em desenvolvimento (série 0.x). Não existe SLA de correção ou compromisso de suporte a versões antigas. A referência atual do aplicativo é 0.6.0; a equipe deve reproduzir o problema no código mantido antes de definir a correção.

## Como relatar

Avise César por canal privado já utilizado pela equipe e combine o envio de detalhes. Se o repositório disponibilizar o recurso **Report a vulnerability**, ele pode ser usado; esta documentação não presume que esteja habilitado. Não publique senhas, tokens, bancos, dumps, dados pessoais ou passos que exponham uma instalação ativa em uma Issue pública.

Inclua versão/commit, ambiente, componente afetado, impacto e reprodução mínima com dados fictícios. Não realize testes em redes, contas ou dispositivos de terceiros. O repositório não oferece programa de recompensa.
